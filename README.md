# SCCP Hax

Site Corinthians/Haxball com conta, anúncios, fotos e Chat Timão.

O código está na pasta `SCCP Hax Site Render/`. O `render.yaml` da raiz aponta para essa pasta e cria o servidor Node e o PostgreSQL gratuitos.

## Publicar

[Abrir configuração no Render](https://dashboard.render.com/blueprint/new?repo=https%3A%2F%2Fgithub.com%2FKahlebizi%2FSCCP)

Entre na sua conta Render, selecione este repositório e confirme o Blueprint. Preencha `ADMIN_PASSWORD_HASH` com o hash do arquivo `.env` da sua cópia local em Downloads/SCCP Hax Site Render. Não use a senha em texto puro nesse campo, nem envie o `.env` para o GitHub.

O administrador é `KahLebz`. Depois de entrar no site, acesse Notícias e clique em Publicar anúncio.

O banco PostgreSQL gratuito expira após 30 dias. Faça backup ou migre antes do vencimento. Os dados e contas da hospedagem anterior não são transferidos automaticamente.

Consulte o guia completo em [LEIA-ME](<SCCP Hax Site Render/LEIA-ME.md>).
